# Titanic Data Analytics Project

## Overview
This project focuses on analyzing the Titanic dataset using Python and Power BI to uncover meaningful insights about passenger survival patterns and demographics.

## Objectives
- Perform data cleaning and preprocessing
- Analyze passenger survival trends
- Visualize important insights using charts and dashboards
- Build an interactive Power BI dashboard

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI

## Key Insights
- Female passengers had higher survival rates
- Passenger class significantly affected survival chances
- Age and fare distribution showed important patterns
- Interactive dashboard helped visualize trends effectively

## Features
- Data Cleaning & Processing
- Exploratory Data Analysis (EDA)
- Interactive Power BI Dashboard
- Data Visualization

## Project Files
- Titanic_Analysis.ipynb
- Titanic_Dashboard.pbix
- dataset.csv

## Conclusion
This project helped in understanding real-world data analysis workflows including preprocessing, visualization, and dashboard creation using modern analytics tools.
